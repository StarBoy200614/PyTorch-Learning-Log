# PyTorch Learning Log 🔥

Documenting my journey through [PyTorch for Deep Learning](https://www.youtube.com/watch?v=LyJtbe__2i0) by Daniel Bourke — notebooks, notes, and small projects built along the way.

## Progress

- [ ] **01 — PyTorch & Deep Learning Basics** 🧠
  Traditional programming vs. ML, why PyTorch, GPU/CUDA acceleration.
- [ ] **02 — Tensor Fundamentals** 🧱
  Creating tensors, tensor ops, reshaping/stacking/squeezing/permuting, NumPy interop.
- [ ] **03 — The PyTorch Workflow** 🔄
  Data prep, subclassing `nn.Module`, training loop, saving/loading models.
- [ ] **04 — Linear Regression from Scratch** 📈
  Custom model, SGD, L1Loss, learning weights & biases.
- [ ] **05 — Neural Network Classification** 🐶🐱
  Binary & multi-class classification, ReLU/Sigmoid/Softmax, `torchmetrics`.
- [ ] **06 — Computer Vision & CNNs** 👁️
  TorchVision, FashionMNIST, TinyVGG, `Conv2d` / `MaxPool2d`.
- [ ] **07 — Custom Datasets** 🍕🥩🍣
  Food101 subset, custom `Dataset` class, data augmentation.
- [ ] **08 — Going Modular** 💻
  `data_setup.py`, `model_builder.py`, `engine.py`, `train.py`, CLI training.
